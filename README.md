# JSA Website

This fully bilingual website was built by Matthew Rohde for the Japanese Student Association club at CSU Northridge.  
  
Deployed on Vercel at a custom domain. A lightweight i18n layer swaps every UI string, board bio, and FAQ at runtime with no reload. The membership sign-up form posts to a serverless Google Apps Script + Google Sheets backend, with server-side email de-duplication, honeypot spam filtering, and input validation.
